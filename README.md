# Lastbite

**Lastbite** adalah platform marketplace makanan yang menghubungkan toko/restoran dengan konsumen untuk menjual kelebihan stok makanan di penghujung hari dengan harga diskon. Solusi ini mengubah potensi limbah menjadi keuntungan ekonomi (Revenue) dan menjaga lingkungan (Eco-friendly).

## 🌍 Latar Belakang Masalah

*   **Limbah Pangan:** Indonesia menghasilkan 23-48 juta ton limbah makanan per tahun, yang berdampak pada emisi gas rumah kaca dan kerugian ekonomi.
*   **Kerugian Mitra:** Pelaku usaha kuliner sering mengalami kerugian akibat stok makanan layak konsumsi yang tidak terjual menjelang jam tutup toko.
*   **Akses Konsumen:** Kurangnya informasi bagi konsumen untuk mendapatkan makanan murah yang masih layak makan.

## 💡 Solusi

**Lastbite** hadir sebagai solusi marketplace makanan yang menghubungkan toko/restoran dengan konsumen untuk menjual kelebihan stok makanan di penghujung hari dengan harga diskon.

## 🚀 Fitur Utama (Customer App)

*   **Pencarian & Filter:** Temukan makanan terdekat berdasarkan lokasi atau kategori.
*   **Order & Cart:** Kemudahan memesan dan mengatur keranjang belanja.
*   **Real-time Tracking:** Status pesanan dari "Menunggu Konfirmasi" hingga "Selesai".
*   **Rating System:** Memberikan ulasan untuk transparansi kualitas makanan.

## 👥 Target Pengguna

*   **Mahasiswa/Masyarakat Umum:** Pencari makanan hemat budget.
*   **UMKM Kuliner/Restoran:** Penjual yang ingin meminimalisir kerugian stok sisa.

## 🛠 Teknis & Metode

### Arsitektur & Teknologi

*   **Mobile Framework:** React Native (Expo) - Cross-platform Android/iOS
*   **State Management:** Redux Toolkit
*   **API Integration:** Axios (REST API Connection)
*   **Styling:** NativeWind (Tailwind CSS)
*   **Design UI/UX:** Figma
*   **Development Tools:** VS Code, Expo, Android Studio

### Metode Pengembangan

*   **Agile (Scrum)** dengan tahapan iteratif: Perencanaan (Sprint Planning) -> Perancangan -> Pengembangan -> Pengujian (Unit Testing) -> Evaluasi.
